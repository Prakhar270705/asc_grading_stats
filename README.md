# asc_grading_stats
download/clone the repo.
open chrome(or brave) and go to chrome://extensions
enable developer mode in the top right corner.
click "Load unpacked" in the top left.
select the ext_src folder from the downloaded repo.
login to asc.iitb.ac.in. go to grading statistics
click the extension icon in the browser toolbar.
enter course codes in this format {CS101}{MA105}{CE102}.
wait for the extension to do its work.
use the Copy Table button to paste data into Excel.
