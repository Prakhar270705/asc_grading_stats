1) download/clone the repo.
2) open chrome(or brave) and go to chrome://extensions
3) enable developer mode in the top right corner.
4) click "Load unpacked" in the top left.
5) select the ext_src folder from the downloaded repo.
6) login to asc.iitb.ac.in. go to grading statistics
7) click the extension icon in the browser toolbar.
8) enter course codes in this format {CS101}{MA105}{CE102}.
9) wait for the extension to do its work.
10) use the Copy Table button to paste data into Excel.
